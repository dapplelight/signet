`touch` and `icon-touch` are 44px, the minimum touch target in WCAG 2.5.5 and Apple's HIG. Use them on phone-first screens.

## Props

Everything from the UI SDK's `Button` (`disabled`, `type`, `render`, event handlers, any `<button>` attribute), plus:

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"default" \| "outline" \| "secondary" \| "ghost" \| "destructive" \| "link"` | `"default"` |
| `size` | `"default" \| "xs" \| "sm" \| "lg" \| "touch" \| "icon" \| "icon-xs" \| "icon-sm" \| "icon-lg" \| "icon-touch"` | `"default"` |
| `className` | `string` | merged last, so it wins |

## Accessibility

| Key | Action |
| --- | --- |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | Activates the button |
| <kbd>Tab</kbd> | Moves focus; a ring shows on keyboard focus only |

- Icon-only sizes (`icon*`) need an `aria-label`.
- `disabled` removes pointer events and dims the button.

## Customisation

1. **Tokens:** colours come from `--primary`, `--destructive`, `--border-default`; change them in your theme.
2. **Props:** `variant` and `size`.
3. **className + data-\*:** `className` merges last. Target `[data-slot="button"]` from CSS.
4. **Parts:** one part. Use `render` to render as a link or another element.
5. **Copy-in:** `signet add button` and edit the source.
