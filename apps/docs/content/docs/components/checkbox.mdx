### Controlled

<Preview>
  <CheckboxControlledDemo />

```tsx
import * as React from "react"
import { Checkbox } from "@dapplelight/signet-ui/components/checkbox"
import { invoices, toggle } from "./invoices"

const [selected, setSelected] = React.useState<string[]>(["INV-2041"])

{invoices.map((id) => (
  <div key={id} className="flex items-center gap-2">
    <Checkbox
      id={id}
      checked={selected.includes(id)}
      onCheckedChange={(v) => toggle(id, v === true)}
    />
    <label htmlFor={id}>{id}</label>
  </div>
))}
```

</Preview>

## API Reference

### Checkbox

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `checked` | `boolean \| "indeterminate"` | - | Controlled state. |
| `defaultChecked` | `boolean \| "indeterminate"` | - | Initial state when uncontrolled. |
| `onCheckedChange` | `(checked: boolean \| "indeterminate") => void` | - | Runs when the state changes. |
| `disabled` | `boolean` | `false` | Prevents interaction. |
| `required` | `boolean` | `false` | Marks it required in a form. |
| `name` | `string` | - | Form field name. |
| `value` | `string` | `"on"` | Form value when checked. |
| `className` | `string` | - | Merged last. |

Built on a Radix checkbox, so it takes every `button` prop. Pair it with a `label` using `id` and `htmlFor`.
