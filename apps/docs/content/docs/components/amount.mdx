## API Reference

### Amount

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `number \| string \| bigint` | — | The amount. Use a bigint for exact minor units. |
| `currency` | `string` | `"INR"` | ISO 4217 code. |
| `locale` | `string` | `"en-IN"` | Indian locales group by lakh and crore. |
| `minorUnits` | `boolean` | `false` | `value` is in paise or cents: 12345 INR is ₹123.45. |
| `notation` | `"standard" \| "whole" \| "compact"` | `"standard"` | Standard shows the currency's decimals, whole none, compact shortens (₹12.5L, $1.3M). |
| `decimals` | `number` | — | Overrides the number of decimals. In compact notation it is the maximum (default 1). |
| `tone` | `"credit" \| "debit" \| "transfer" \| "auto"` | — | Colour from the theme's money slots. `auto` picks credit or debit from the sign. |
| `signDisplay` | `Intl.NumberFormatOptions["signDisplay"]` | `"auto"` | Defaults to `exceptZero` when `tone` is `auto`, so the sign is never shown by colour alone. |
| `classNames` | `Partial<Record<AmountPart, string>>` | — | Classes per part: `sign`, `currency`, `integer`, `fraction`, `compact`. |
| `render` | `React.ReactElement` | — | Replaces the `<data>` element, keeping props and parts. |
| `title` | `string` | — | Compact amounts default to the full amount on hover. |

### formatAmount

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `AmountValue` | — | The amount to format. |
| `options` | `Pick<AmountProps, "currency" \| "locale" \| "minorUnits" \| "notation" \| "decimals" \| "signDisplay">` | `{}` | Same options as the component. Returns `{ parts, major, sign }`, for table cells and chart labels. |
