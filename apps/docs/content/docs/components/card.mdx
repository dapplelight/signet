## Usage

```tsx

  Card,
  CardAction,
  CardContent,
  CardDescription,
  CardFooter,
  CardHeader,
  CardTitle,
} from "@dapplelight/signet-ui/components/card"

<Card>
  <CardHeader>
    <CardTitle>Title</CardTitle>
    <CardDescription>Description</CardDescription>
  </CardHeader>
  <CardContent>Content</CardContent>
  <CardFooter>Footer</CardFooter>
</Card>
```

## API Reference

### Card

| Prop | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| `size` | `"default" \| "sm"` | `"default"` | No | `sm` tightens the padding and gaps. |
| `className` | `string` | — | No | Merged last. A first-child `img` runs edge to edge. |

Plus every native [`<div>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/div) attribute.

### CardHeader, CardTitle, CardDescription, CardAction, CardContent, CardFooter

| Prop | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| `className` | `string` | — | No | Merged last. |

Plus every native [`<div>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/div) attribute. `CardAction` sits at the top right of `CardHeader`. `CardFooter` has a top border and a tinted background.
