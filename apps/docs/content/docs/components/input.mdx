## API Reference

### Input

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `type` | `string` | `"text"` | Any HTML input type. |
| `className` | `string` | none | Merged last. |

Plus every `<input>` prop. Set `aria-invalid` for the error style.
