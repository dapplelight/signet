## API Reference

### Input

| Prop | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| `type` | `string` | `"text"` | No | Any HTML input type. |
| `aria-invalid` | `boolean` | — | No | Shows the error style. |
| `className` | `string` | — | No | Merged last. |

Plus every native [`<input>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/input) attribute.
