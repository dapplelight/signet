## Examples

### With a list

<Preview>
  <PaginationListDemo />

```tsx
const invoices = Array.from({ length: 12 }, (_, i) => `INV-${1040 + i}`)

export function InvoiceList() {
  const [page, setPage] = useState(1)
  const size = 4
  const totalPages = Math.ceil(invoices.length / size)
  return (
    <>
      <ul>
        {invoices.slice((page - 1) * size, page * size).map((id) => (
          <li key={id}>{id}</li>
        ))}
      </ul>
      <Pagination page={page} totalPages={totalPages} onPageChange={setPage} />
    </>
  )
}
```

</Preview>

## API Reference

### Pagination

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| page | `number` | - | Current page, starting at 1. |
| totalPages | `number` | - | Total pages. Nothing renders at 1 or less. |
| onPageChange | `(page: number) => void` | - | Called with the new page, clamped to the range. |
| className | `string` | - | Class on the wrapper. |
