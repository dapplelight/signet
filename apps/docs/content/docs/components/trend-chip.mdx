## API Reference

### TrendChip

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `number \| string` | — | The change in percent. Strings are parsed; a non-number shows a dash. |
| `className` | `string` | — | Merged over the 11px default. |
