### Clickable rows

<Preview>
  <DataTableClickableDemo />

```tsx
import { useState } from "react"
import { DataTable } from "@dapplelight/signet-ui/components/data-table"

// uses the invoices and columns from the first example
export function Demo() {
  const [open, setOpen] = useState<Invoice | null>(null)
  return (
    <div className="w-full space-y-2">
      <DataTable
        columns={columns}
        data={invoices}
        getRowId={(r) => r.id}
        onRowClick={setOpen}
        getRowLabel={(r) => `Open ${r.id} for ${r.customer}`}
      />
      <p className="text-sm text-muted-foreground">
        {open ? `${open.id}: ${open.customer}` : "Click a row"}
      </p>
    </div>
  )
}
```

## API Reference

### DataTable

Every feature is off by default and opt-in by prop. There is no built-in pagination: scroll long lists with `virtual`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `columns` | `ColumnDef<DataTableFeatures, TData, unknown>[]` | required | TanStack column definitions. Set `meta.filter` to `"facet"` or `"text"` for a toolbar filter, and `meta.filterLabel` to name it. |
| `data` | `TData[]` | required | The rows. |
| `getRowId` | `(row: TData, index: number) => string` | row index | Stable row ids, for selection and `activeRowId`. |
| `sortable` | `boolean` | `false` | Click a header to sort; shift-click adds a column. |
| `selectable` | `boolean` | `false` | Checkbox column, select-all header and a bulk-actions bar. |
| `selectedRowIds` | `readonly string[]` | none | Controlled selection. |
| `onSelectedRowIdsChange` | `(ids: string[]) => void` | none | Called when selection changes. |
| `bulkActions` | `(selected: TData[]) => ReactNode` | none | Rendered in the bulk bar while rows are selected. |
| `searchable` | `boolean \| { placeholder?: string }` | `false` | A search box across every visible column. |
| `columnsMenu` | `boolean` | `false` | A menu to show and hide columns. |
| `exportFilename` | `string` | none | Adds an export button that downloads the current view as `<name>.csv`. |
| `onRowClick` | `(row: TData) => void` | none | Makes rows clickable and keyboard focusable. |
| `getRowLabel` | `(row: TData) => string` | none | Accessible name for a clickable row. |
| `activeRowId` | `string` | none | Row marked `data-active` and scrolled into view. |
| `emptyMessage` | `string` | none | Shown when there are no rows. |
| `virtual` | `{ rowHeight: number; height: number \| string; overscan?: number }` | none | Render only visible rows, under a sticky header. Keep cells to one line. |
| `view` | `DataTableView` | none | Controlled filters, sorting and column visibility. |
| `defaultView` | `DataTableView` | empty | Starting view when uncontrolled. |
| `onViewChange` | `(view: DataTableView) => void` | none | Called when the view changes. |
| `savedViews` | `{ views: SavedView[]; onSave: (name, view) => void; onDelete?: (id) => void }` | none | Named views in the toolbar. |
| `manual` | `boolean` | `false` | The server filters and sorts; `data` is shown as given. |
| `facetCounts` | `Record<string, Record<string, number>>` | computed | Server-side counts per facet value. |
| `total` | `number` | `data.length` | Unfiltered row count, for "12 of 10,000". |
| `tableRef` | `MutableRefObject<Table \| undefined>` | none | Exposes the TanStack table instance. |
| `className` | `string` | none | Class for the root. |

### TruncatedCell

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `children` | `ReactNode` | required | Cell content; a tooltip shows when a string or number is cut off. |
| `className` | `string` | none | Class for the cell. |
