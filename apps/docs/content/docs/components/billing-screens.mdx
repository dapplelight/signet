## Usage

```tsx
import { BillingScreen, PlanPicker, CurrentPlanCard, UsageMeters, InvoiceList, WalletCard, Paywall, RestorePurchasesButton } from "@dapplelight/signet-ui/screens/billing-screens"
```

```tsx
<BillingScreen plans={plans} subscription={subscription} usage={usage} invoices={invoices} onSubscribe={checkout} />
```

`plansFromEntitlements(plans, display)` builds the plan list from a `definePlans` object, and `formatMoney(amount, currency)` formats minor units.

## API Reference

### BillingScreen

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `plans` | `readonly BillingPlan[]` | — | Plans to show. Build them with `plansFromEntitlements`. |
| `subscription` | `BillingSubscription` | — | Pass `ent.resolve(subject)` as it is. |
| `usage` | `readonly BillingUsage[]` | — | One meter per limit. |
| `invoices` | `readonly BillingInvoice[]` | — | Invoices, newest first. |
| `wallet` | `{ balance: number; currency: string; onTopUp?: () => void }` | — | Shows a wallet card. |
| `source` | `BillingSource` | `"web"` | Where the app runs. Plans not sold there are hidden. |
| `onSubscribe` | `(plan: BillingPlan, interval: BillingInterval) => unknown` | — | Start checkout or the store purchase. |
| `onManage` | `() => void` | — | Shows a Manage button. |
| `onRestore` | `() => Promise<unknown> \| unknown` | — | Restore store purchases. |
| `labels` | `Partial<BillingLabels>` | — | Every string, in English by default. Spread `DEFAULT_BILLING_LABELS` to translate. |
| `classNames` | `Partial<Record<"current" \| "usage" \| "wallet" \| "plans" \| "invoices", string>>` | — | Classes per part. |

### PlanPicker

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `plans` | `readonly BillingPlan[]` | — | Plan cards: `key`, `name`, `description`, `features`, `limits`, `prices`, `badge`, `sources`. |
| `value` | `string` | — | Selected plan key (controlled). |
| `defaultValue` | `string` | — | Initial plan key. |
| `onValueChange` | `(plan: string) => void` | — | Called when the selection changes. |
| `interval` | `"month" \| "year" \| "once"` | — | Billing interval (controlled). |
| `defaultInterval` | `BillingInterval` | — | Initial interval. |
| `onIntervalChange` | `(interval: BillingInterval) => void` | — | Called when the interval changes. |
| `currentPlan` | `string` | — | The subscriber's plan key: marked, and its button is disabled. |
| `source` | `BillingSource` | `"web"` | Where this purchase happens. Plans not sold there are hidden. |
| `onSubscribe` | `(plan: BillingPlan, interval: BillingInterval) => unknown` | — | A returned Promise keeps the button pending. |
| `labels` | `Partial<BillingLabels>` | — | Every string, in English by default. Spread `DEFAULT_BILLING_LABELS` to translate. |
| `classNames` | `Partial<Record<"intervals" \| "plans" \| "plan" \| "price" \| "features" \| "cta", string>>` | — | Classes per part. |

### CurrentPlanCard

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `subscription` | `BillingSubscription` | — | `plan`, `status`, `currentPeriodEnd`, `graceUntil`, `source`. |
| `plans` | `readonly BillingPlan[]` | `[]` | Used to show the plan's name. |
| `onManage` | `() => void` | — | Shows a Manage button. |
| `onRestore` | `() => Promise<unknown> \| unknown` | — | Shown when the subscription came from a store. |
| `source` | `BillingSource` | — | Where the app runs. A store here shows Restore even without a subscription. |
| `labels` | `Partial<BillingLabels>` | — | Every string, in English by default. Spread `DEFAULT_BILLING_LABELS` to translate. |

### UsageMeters

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `usage` | `readonly BillingUsage[]` | — | One bar per limit; amber at 75%, red at 90%. |
| `labels` | `Partial<BillingLabels>` | — | Every string, in English by default. Spread `DEFAULT_BILLING_LABELS` to translate. |

### InvoiceList

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `invoices` | `readonly BillingInvoice[]` | — | Each opens its GST HTML invoice in a new tab. |
| `labels` | `Partial<BillingLabels>` | — | Every string, in English by default. Spread `DEFAULT_BILLING_LABELS` to translate. |

### WalletCard

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `balance` | `number` | — | In minor units. |
| `currency` | `string` | — | ISO 4217 code. |
| `onTopUp` | `() => void` | — | Shows a top-up button. |
| `labels` | `Partial<BillingLabels>` | — | Every string, in English by default. Spread `DEFAULT_BILLING_LABELS` to translate. |

### Paywall

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `title` | `ReactNode` | `labels.paywallTitle` | Headline. |
| `subtitle` | `ReactNode` | `labels.paywallSubtitle` | Text under the headline. |
| `onRestore` | `() => Promise<unknown> \| unknown` | — | In a store build (`source` is `appstore` or `googleplay`), shows Restore. |
| `...PlanPickerProps` | `PlanPickerProps` | — | Every PlanPicker prop is passed through. |

### RestorePurchasesButton

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `onRestore` | `() => Promise<unknown> \| unknown` | — | Ask the store and re-apply purchases. Resolve false when nothing was found. |
| `labels` | `Partial<BillingLabels>` | — | Every string, in English by default. Spread `DEFAULT_BILLING_LABELS` to translate. |
