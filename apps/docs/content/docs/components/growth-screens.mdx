## Usage

```tsx
import {
  WaitlistJoin,
  InviteAccept,
  ReferralCard,
  OnboardingChecklist,
  FeedbackWidget,
  WhatsNew,
} from "@dapplelight/signet-ui/screens/growth-screens"
```

Data is shaped like signet-db's growth module results; actions come out as callbacks.

```tsx
import { WaitlistJoin } from "@dapplelight/signet-ui/screens/growth-screens"

<WaitlistJoin onJoin={(email) => growth.joinWaitlist(email)} />
```

## API Reference

All screens accept `labels` (`Partial<GrowthLabels>`, defaults in `DEFAULT_GROWTH_LABELS`) except where noted, and the props of their root element.

### WaitlistJoin

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `onJoin` | `(email: string) => Promise<WaitlistResult> \| WaitlistResult` | required | Join and return the place in line. |
| `result` | `WaitlistResult \| null` | - | The result (controlled), e.g. from an earlier visit. |
| `defaultResult` | `WaitlistResult \| null` | - | Initial result when uncontrolled. |
| `onResultChange` | `(result: WaitlistResult \| null) => void` | - | Called when the result changes. |
| `title` | `ReactNode` | - | Heading override. |

### InviteAccept

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `invite` | `InviteDetails` | required | Inviter, scope, role, email and expiry. |
| `onAccept` | `() => Promise<InviteAcceptResult> \| InviteAcceptResult` | required | Accept the invite. |
| `onDecline` | `() => void` | - | Shows Decline when set. |
| `onAccepted` | `() => void` | - | Called after a successful accept, e.g. to navigate. |
| `error` | `"not_found" \| "expired" \| "used" \| "revoked" \| "email_mismatch"` | - | Show a failure straight away. |

### ReferralCard

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `code` | `string` | required | The referral code. |
| `url` | `string` | required | The link that carries the code. |
| `stats` | `{ referred: number; converted: number; rewarded: number }` | - | Counts of friends. |
| `onShare` | `(url: string) => void` | Web Share API, else copy | Replaces the share action. |
| `title` | `ReactNode` | - | Heading override. |

### OnboardingChecklist

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `steps` | `readonly OnboardingStep[]` | required | `key`, `title` and optional `description`. |
| `done` | `readonly string[]` | - | Done step keys (controlled). |
| `defaultDone` | `readonly string[]` | - | Initial done keys when uncontrolled. |
| `onDoneChange` | `(done: string[]) => void` | - | Called when done keys change. |
| `onStepSelect` | `(step: OnboardingStep) => void` | - | A step was chosen: take the user there. |
| `onDismiss` | `() => void` | - | Shows Dismiss when set. |
| `title` | `ReactNode` | - | Heading override. |

### FeedbackForm

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `onSubmit` | `(input: FeedbackInput) => Promise<unknown> \| unknown` | required | Send the feedback. |
| `kinds` | `readonly string[]` | bug, idea, praise, other | Feedback kinds. |
| `rating` | `boolean` | - | Ask for 1 to 5 stars too. |
| `defaultKind` | `string` | - | The kind selected first. |

### FeedbackWidget

Takes every `FeedbackForm` prop, plus:

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `open` | `boolean` | - | Popover open state (controlled). |
| `defaultOpen` | `boolean` | `false` | Initial open state. |
| `onOpenChange` | `(open: boolean) => void` | - | Called when it opens or closes. |
| `trigger` | `ReactElement` | - | Replaces the trigger button. |
| `contentClassName` | `string` | - | Class on the popover content. |

### WhatsNew

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `entries` | `readonly ChangelogEntry[]` | required | Every entry, newest first. |
| `unseen` | `number` | `0` | How many are unseen. |
| `onOpen` | `() => void` | - | Opened: mark them seen. |
| `open` | `boolean` | - | Open state (controlled). |
| `defaultOpen` | `boolean` | `false` | Initial open state. |
| `onOpenChange` | `(open: boolean) => void` | - | Called when it opens or closes. |
| `trigger` | `ReactElement` | - | Replaces the trigger button. |
| `className` | `string` | - | Class on the trigger. |
| `contentClassName` | `string` | - | Class on the popover content. |
