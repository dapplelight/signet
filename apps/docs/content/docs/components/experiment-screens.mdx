## Usage

```tsx
import {
  ExperimentList,
  ExperimentResults,
  ExperimentForm,
  PricingExperimentResults,
} from "@dapplelight/signet-ui/screens/experiment-screens"
```

Data is shaped like signet-db's `createExperiments` results or the `experimentAdminRoutes` JSON; actions come out as callbacks that may be async. An action that throws or resolves `false` shows the failure message.

```tsx
<ExperimentResults experiment={experiment} results={results} onStop={stop} />
```

## API Reference

All screens also accept the props of their root element and `labels` (`Partial<ExperimentLabels>`, defaults in `DEFAULT_EXPERIMENT_LABELS`).

### ExperimentList

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `experiments` | `readonly ExperimentView[]` | required | Experiments to list. |
| `selected` | `string` | - | Key of the experiment shown, marked `aria-current`. |
| `onSelect` | `(key: string) => void` | - | Called when one is picked. |

### ExperimentResults

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `experiment` | `ExperimentView` | required | The experiment. |
| `results` | `ExperimentResultsView \| null` | - | Per-variant results; null when the server has no events table. |
| `onStart` | `() => unknown` | - | Start or resume. |
| `onStop` | `() => unknown` | - | Stop. |
| `onRollout` | `(variant: string) => unknown` | - | Roll out a variant. |

### ExperimentForm

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `experiment` | `ExperimentView` | - | The experiment to edit; omitted creates one. |
| `offerings` | `readonly OfferingChoice[]` | - | Offerings to pick per variant (pricing experiment); omitted shows a JSON value field. |
| `onSubmit` | `(input: ExperimentInputView) => unknown` | required | Create or save. Resolve `false` or throw to show the failure. |
| `onStart` | `() => unknown` | - | Start the experiment. |
| `onStop` | `() => unknown` | - | Stop the experiment. |

### PricingExperimentResults

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `experiment` | `ExperimentView` | required | The experiment. |
| `readout` | `PricingReadoutView` | required | Per-variant offering, conversion, trial conversion, revenue and LTV. |
| `onRollout` | `(variant: string) => unknown` | - | Make a variant's offering the placement's offering. |
| `onStart` | `() => unknown` | - | Start the experiment. |
| `onStop` | `() => unknown` | - | Stop the experiment. |

### ExperimentStatusBadge

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `status` | `"draft" \| "running" \| "stopped" \| "rolled_out"` | required | Status to show. |
| `labels` | `Partial<ExperimentLabels>` | - | Override any string. |
