## Usage

```tsx
import {
  DropdownMenu,
  DropdownMenuContent,
  DropdownMenuItem,
  DropdownMenuTrigger,
} from "@dapplelight/signet-ui/components/dropdown-menu"
```

```tsx
<DropdownMenu>
  <DropdownMenuTrigger asChild>
    <Button variant="outline">Open</Button>
  </DropdownMenuTrigger>
  <DropdownMenuContent>
    <DropdownMenuItem>Profile</DropdownMenuItem>
  </DropdownMenuContent>
</DropdownMenu>
```

## Examples

### Checkboxes

<Preview>
  <DropdownMenuCheckboxesDemo />

```tsx
import { useState } from "react"
import { Button } from "@dapplelight/signet-ui/components/button"
import { DropdownMenu, DropdownMenuCheckboxItem, DropdownMenuContent, DropdownMenuLabel, DropdownMenuSeparator, DropdownMenuTrigger } from "@dapplelight/signet-ui/components/dropdown-menu"

export function Demo() {
  const [showStatus, setShowStatus] = useState(true)
  const [showDue, setShowDue] = useState(false)
  return (
    <DropdownMenu>
      <DropdownMenuTrigger asChild>
        <Button variant="outline">Columns</Button>
      </DropdownMenuTrigger>
      <DropdownMenuContent className="w-48">
        <DropdownMenuLabel>Show columns</DropdownMenuLabel>
        <DropdownMenuSeparator />
        <DropdownMenuCheckboxItem checked={showStatus} onCheckedChange={setShowStatus}>
          Status
        </DropdownMenuCheckboxItem>
        <DropdownMenuCheckboxItem checked={showDue} onCheckedChange={setShowDue}>
          Due date
        </DropdownMenuCheckboxItem>
      </DropdownMenuContent>
    </DropdownMenu>
  )
}
```

## API Reference

Built on Radix's Dropdown Menu. Every part takes that primitive's props; these are the Signet additions.

### DropdownMenu

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `open` | `boolean` | - | Controlled open state. |
| `defaultOpen` | `boolean` | `false` | Initial state when uncontrolled. |
| `onOpenChange` | `(open: boolean) => void` | - | Runs when it opens or closes. |
| `modal` | `boolean` | `true` | Block pointer interaction outside while open. |

### DropdownMenuContent

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `sideOffset` | `number` | `4` | Gap from the trigger in px. |
| `side` | `"top" \| "right" \| "bottom" \| "left"` | `"bottom"` | Preferred side; flips when there is no room. |
| `align` | `"start" \| "center" \| "end"` | `"center"` | Alignment against the trigger. |
| `loop` | `boolean` | `false` | Wrap arrow keys at the ends. |
| `className` | `string` | none | Merged onto the content. Rendered in a portal. |

### DropdownMenuItem, DropdownMenuLabel, DropdownMenuSubTrigger

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `inset` | `boolean` | `false` | Indent to line up with items that have an indicator. |
| `onSelect` (`DropdownMenuItem`) | `(event: Event) => void` | - | Runs on choice; `event.preventDefault()` keeps the menu open. |
| `disabled` (`DropdownMenuItem`, `DropdownMenuSubTrigger`) | `boolean` | `false` | Not focusable or selectable. |
| `className` | `string` | none | Merged last. |

### Other parts

`DropdownMenu`, `DropdownMenuTrigger`, `DropdownMenuGroup`, `DropdownMenuPortal`, `DropdownMenuSub` and `DropdownMenuRadioGroup` are the Radix parts. `DropdownMenuCheckboxItem` (`checked`, `onCheckedChange`), `DropdownMenuRadioItem` (`value`), `DropdownMenuSubContent`, `DropdownMenuSeparator` and `DropdownMenuShortcut` take their Radix props plus `className`.
