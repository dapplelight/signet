## Usage

```tsx
import {
  AvatarStack,
  EditingBadge,
  TypingIndicator,
  RecordChangedBanner,
} from "@dapplelight/signet-ui/screens/realtime-screens"
```

Members are shaped like signet-server's presence (`useChannel(...).members`); `selfId` leaves you out.

```tsx
import { AvatarStack } from "@dapplelight/signet-ui/screens/realtime-screens"
import { members, me } from "./presence"

<AvatarStack members={members} selfId={me.id} />
```

### RecordChangedBanner

Pair with `useRecordChanges`. Renders nothing while `changed` is false.

<Preview>
  <RecordChangedBannerDemo />

```tsx
import { useState } from "react"
import { RecordChangedBanner } from "@dapplelight/signet-ui/screens/realtime-screens"

function RecordChangedBannerDemo() {
  const [changed, setChanged] = useState(true)
  return (
    <div className="w-full max-w-lg">
      <RecordChangedBanner
        changed={changed}
        by="Marcus Lee"
        onReload={() => setChanged(false)}
        onDismiss={() => setChanged(false)}
      />
    </div>
  )
}
```

</Preview>

## API Reference

All components accept `labels` (`Partial<RealtimeLabels>`, defaults in `DEFAULT_REALTIME_LABELS`) and the props of their root element.

### AvatarStack

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `members` | `PresenceMemberView[]` | required | Who is in the channel. |
| `selfId` | `string` | - | Leave yourself out of the stack. |
| `max` | `number` | `4` | Avatars shown before "+n". |
| `size` | `"sm" \| "default" \| "lg"` | `"default"` | Avatar size. |

### EditingBadge

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `members` | `PresenceMemberView[]` | required | Who is in the channel. |
| `selfId` | `string` | - | Leave yourself out. |
| `field` | `string` | any field | Only someone editing this field. |
| `fieldLabel` | `string` | the field | A readable name for the field in the text. |

### TypingIndicator

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `members` | `PresenceMemberView[]` | required | Who is in the channel. |
| `selfId` | `string` | - | Leave yourself out. |

### RecordChangedBanner

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `changed` | `boolean` | required | Show the banner. |
| `by` | `string` | - | Who changed it, if known. |
| `onReload` | `() => void` | required | Reload the record. |
| `onDismiss` | `() => void` | - | Shows a dismiss button when set. |
