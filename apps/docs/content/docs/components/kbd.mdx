
## API Reference

### Kbd

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `children` | `ReactNode` | none | The key label. |
| `className` | `string` | none | Merged last. |

### KeySequence

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `keys` | `string \| string[]` | required | One key per entry, each in its own `Kbd`. |
| `className` | `string` | none | Merged onto the wrapper. |
