## API Reference

### PillGroup

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| options | `PillOption[]` | - | The pills, in order. |
| value | `string` | - | The selected option's value. Use `""` for an All pill. |
| onChange | `(value: string) => void` | - | Called with the clicked pill's value. |
| className | `string` | - | Class on the wrapper. |

### PillOption

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| value | `string` | - | Value passed to `onChange`. |
| label | `string` | - | Text shown in the pill. |
| activeClassName | `string` | primary tint | Replaces the selected style, e.g. a status colour. |
