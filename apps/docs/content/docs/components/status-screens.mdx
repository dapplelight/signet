## Usage

```tsx
import {
  StatusPage,
  StatusAdmin,
} from "@dapplelight/signet-ui/screens/status-screens"
```

Data is shaped like `status.summary()` from signet-db's `createStatus` (or its JSON); admin actions come out as callbacks.

```tsx
import { StatusPage } from "@dapplelight/signet-ui/screens/status-screens"
import { summary } from "./summary"

<StatusPage summary={summary} />
```

## API Reference

All screens accept the props of their root element. `StatusPage` takes `labels` as `Partial<StatusLabels>`; the admin screens take `Partial<StatusAdminLabels>`.

### StatusPage

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `summary` | `StatusSummaryView` | required | Overall status, components, incidents and maintenance. |
| `labels` | `Partial<StatusLabels>` | `DEFAULT_STATUS_LABELS` | Override any string. |

### StatusAdmin

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `summary` | `Omit<StatusSummaryView, "status">` | required | Components, incidents and maintenance. |
| `onMaintenance` | `(input: MaintenanceInput) => unknown` | required | Save the maintenance switch, message and end time. |
| `onComponentStatus` | `(key: string, status: ComponentStatus) => unknown` | required | A component's status changed. |
| `onOpenIncident` | `(input: IncidentInput) => unknown` | required | Open an incident. |
| `onUpdateIncident` | `(id: string, input: { status: string; message: string }) => unknown` | required | Append an update; `"resolved"` closes it. |
| `labels` | `Partial<StatusAdminLabels>` | `DEFAULT_STATUS_ADMIN_LABELS` | Override any string. |

### MaintenanceForm

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `maintenance` | `StatusSummaryView["maintenance"]` | required | Current maintenance state. |
| `onSave` | `(input: MaintenanceInput) => unknown` | required | Called on submit. |
| `labels` | `Partial<StatusAdminLabels>` | - | Override any string. |

### ComponentStatusList

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `components` | `StatusSummaryView["components"]` | required | Components to list. |
| `onStatus` | `(key: string, status: ComponentStatus) => unknown` | required | Called at once when a status changes. |
| `labels` | `Partial<StatusAdminLabels>` | - | Override any string. |

### IncidentForm

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `components` | `StatusSummaryView["components"]` | required | Components the incident can affect. |
| `onOpen` | `(input: IncidentInput) => unknown` | required | Open the incident with its first update. |
| `labels` | `Partial<StatusAdminLabels>` | - | Override any string. |

### IncidentUpdateForm

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `incident` | `StatusIncidentView` | required | The incident and its updates. A resolved one shows no form. |
| `onUpdate` | `(id: string, input: { status: string; message: string }) => unknown` | required | Append an update; `"resolved"` closes it. |
| `labels` | `Partial<StatusAdminLabels>` | - | Override any string. |
