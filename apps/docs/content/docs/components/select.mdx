## Usage

```tsx
import {
  Select,
  SelectContent,
  SelectGroup,
  SelectItem,
  SelectLabel,
  SelectSeparator,
  SelectTrigger,
  SelectValue,
} from "@dapplelight/signet-ui/components/select"

<Select>
  <SelectTrigger className="w-48">
    <SelectValue placeholder="Currency" />
  </SelectTrigger>
  <SelectContent>
    <SelectItem value="usd">USD</SelectItem>
  </SelectContent>
</Select>
```

Built on Base UI's Select.

## API Reference

### Select

Base UI's Select root. Common props:

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| value | `Value \| null` | - | Controlled value. |
| defaultValue | `Value \| null` | - | Initial value when uncontrolled. |
| onValueChange | `(value: Value \| null, details) => void` | - | Called when the selection changes. |
| multiple | `boolean` | false | Allow several values; `value` becomes an array. |
| items | `Record<string, ReactNode> \| { label, value }[]` | - | Lets `SelectValue` show an item's label instead of its raw value. |
| open | `boolean` | - | Controlled open state. |
| defaultOpen | `boolean` | false | Initial open state. |
| onOpenChange | `(open: boolean, details) => void` | - | Called when the popup opens or closes. |
| modal | `boolean` | true | Block outside interaction while open. |
| name | `string` | - | Form field name. |
| disabled | `boolean` | false | Disable the select. |
| readOnly | `boolean` | false | Show the value but block changes. |
| required | `boolean` | false | Require a choice in a form. |

### SelectTrigger

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| size | `"sm" \| "default"` | `"default"` | Trigger height. |
| className | `string` | - | Class on the trigger. `aria-invalid` shows the error style. |

### SelectValue

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| placeholder | `ReactNode` | - | Shown while nothing is selected. |
| children | `ReactNode \| ((value) => ReactNode)` | - | Custom text for the selected value. |

### SelectContent

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| side | `"top" \| "bottom" \| "left" \| "right" \| "inline-start" \| "inline-end"` | `"bottom"` | Preferred side. |
| sideOffset | `number` | 4 | Gap from the trigger. |
| align | `"start" \| "center" \| "end"` | `"center"` | Alignment against the trigger. |
| alignOffset | `number` | 0 | Offset along the alignment axis. |
| alignItemWithTrigger | `boolean` | true | Line the selected item up over the trigger. |

### SelectItem

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| value | `Value` | - | This option's value; any type, matching the root. |
| disabled | `boolean` | false | Disable this option. |
| children | `ReactNode` | - | Label. A truncated label shows a tooltip on hover. |

### SelectGroup / SelectLabel / SelectSeparator

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| className | `string` | - | Group options under a label, and split groups with a separator. |
