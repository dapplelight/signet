## Usage

```tsx
import { Badge } from "@dapplelight/signet-ui/components/badge"

<Badge variant="secondary">Draft</Badge>
```

## API Reference

### Badge

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `default` \| `secondary` \| `destructive` \| `outline` \| `ghost` \| `link` | `default` | Visual style. |
| `render` | `ReactElement \| function` | - | Render as another element, such as a link. |
| `className` | `string` | - | Merged last. |

Renders a `span` and accepts every `span` prop. Set `data-icon="inline-start"` or `"inline-end"` on an icon to tighten the padding on that side. `badgeVariants` is exported for styling your own element.
