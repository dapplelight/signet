## Usage

```tsx
import {
  Timeline,
  TimelineConnector,
  TimelineDescription,
  TimelineItem,
  TimelineMarker,
  TimelineTime,
  TimelineTitle,
} from "@dapplelight/signet-ui/components/timeline"

<Timeline aria-label="Order history">
  <TimelineItem status="complete">
    <TimelineMarker />
    <TimelineConnector />
    <TimelineTitle>Order placed</TimelineTitle>
    <TimelineTime>9:12 AM</TimelineTime>
  </TimelineItem>
</Timeline>
```

## API Reference

`Timeline`

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `aria-label` | `string` | `-` | Names the list. Give it one. |
| `className` | `string` | `-` | Merged over `flex flex-col`. |

`TimelineItem`

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `status` | `"complete" \| "current" \| "upcoming"` | `-` | Marks progress and sets `aria-current` on the current item. |

`TimelineMarker` (the dot; pass an icon as children to replace it), `TimelineConnector` (the line to the next item, hidden on the last), `TimelineTitle`, `TimelineTime` and `TimelineDescription` take only `className` plus the props of the UI SDK timeline parts they wrap.
