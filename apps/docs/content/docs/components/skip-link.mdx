  )
}

## API Reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `target` | `string` | `"main"` | id of the main content, without `#`. Give that element `tabIndex={-1}` so focus lands on it. |
| `children` | `ReactNode` | `"Skip to content"` | Link text. The default comes from the labels provider (`skipToContent`). |

Plus every native `<a>` prop. Render it first in the layout.
