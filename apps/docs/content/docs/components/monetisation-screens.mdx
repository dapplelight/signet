## Usage

```tsx
import {
  RemotePaywall,
  CustomerCenter,
  CustomerTimeline,
  PromotionalGrantForm,
} from "@dapplelight/signet-ui/screens/monetisation-screens"
```

Data is shaped like signet-db's offerings and customers results (or their JSON); actions come out as callbacks.

```tsx
import { RemotePaywall } from "@dapplelight/signet-ui/screens/monetisation-screens"

<RemotePaywall offering={offering} onPurchase={(product) => checkout(product)} />
```

## API Reference

All screens accept the props of their root element and `labels` (`Partial<MonetisationLabels>`, defaults in `DEFAULT_MONETISATION_LABELS`).

### RemotePaywall

Also takes the `Paywall` props from billing-screens (`value`, `interval`, `currentPlan`, `source`, `onRestore` and so on) except `plans`, `onSubscribe`, `title` and `subtitle`, which come from the offering.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `offering` | `RemoteOffering` | required | The server's current offering with its paywall config. |
| `display` | `Record<string, Partial<BillingPlan>>` | - | Names, descriptions and features per plan key; prices come from the offering. |
| `onPurchase` | `(product, plan, interval, offer?) => unknown` | - | Buy the product through your checkout or store. `offer` is the best offer for this customer. |
| `onImpression` | `(offering: RemoteOffering) => unknown` | - | Called once when the paywall is shown. |

### CustomerCenter

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `overview` | `CustomerOverview` | required | Plan, status, renewal date, source and retention offer. |
| `plans` | `readonly BillingPlan[]` | - | Plans, to name the current one. |
| `onCancel` | `() => unknown` | - | Cancel a web subscription. Resolve `false` on failure. |
| `onAcceptRetention` | `() => unknown` | - | Accept the retention offer shown before cancelling. |
| `onRequestRefund` | `(reason: string) => unknown` | - | Request a refund of the latest payment. |
| `onContactSupport` | `(message: string) => unknown` | - | Send a message to support. |
| `onRestore` | `() => unknown` | - | Restore earlier store purchases. |

### CustomerTimeline

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `entries` | `readonly CustomerTimelineEntry[]` | required | Billing events across App Store, Google Play and web, newest first. |
| `totals` | `readonly CustomerTimelineTotal[]` | `[]` | Ledger totals per currency. |

### PromotionalGrantForm

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `plans` | `readonly string[]` | required | Plan keys an admin may grant. |
| `defaultDays` | `number` | `30` | Days preselected. |
| `onGrant` | `(grant: { plan: string; days: number; note?: string }) => unknown` | required | Grant the plan; it lapses on its own. |

### plansFromOffering

`plansFromOffering(offering, source = "web", display = {}, badge?)` returns the `BillingPlan[]` for one source, ready for `PlanPicker`.
