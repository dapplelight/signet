## Usage

```tsx
import {
  RichTextContent,
  RichTextEditor,
} from "@dapplelight/signet-ui/components/rich-text-editor"
```

```tsx
<RichTextEditor value={note} onValueChange={setNote} aria-label="Account note" />
```

Needs the optional peers `@tiptap/react`, `@tiptap/pm`, `@tiptap/starter-kit`, `@tiptap/extension-mention` and `@tiptap/extension-link`. Mentions are stored as `@[Name](user:id)`.

## Examples

### Mentions

<Preview>
  <RichTextEditorMentionsDemo />

```tsx
const team: RichTextPerson[] = [
  { id: "u_1", name: "Priya Shah" },
  { id: "u_2", name: "Marcus Lee" },
  { id: "u_3", name: "Dana Ortiz" },

  aria-label="Comment"
  placeholder="Type @ to mention a teammate"
  onMentionSearch={(q) =>
```

## API Reference

### RichTextEditor

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| value | `string` | - | Markdown. Controlled with `onValueChange`. |
| defaultValue | `string` | `""` | Initial markdown when uncontrolled. |
| onValueChange | `(markdown: string) => void` | - | Called with the new markdown on every edit. |
| onMentionSearch | `(query: string) => Promise<RichTextPerson[]> \| RichTextPerson[]` | - | People matching the query. Leave out to turn mentions off. |
| onRequestLink | `(current: string) => Promise<string \| null> \| string \| null` | window.prompt | Ask for a link address. Unsafe addresses are ignored. |
| formats | `readonly RichTextFormat[]` | all | Toolbar buttons, in order: `bold`, `italic`, `code`, `link`, `h2`, `h3`, `ul`, `ol`. |
| placeholder | `string` | - | Hint shown while empty. |
| disabled | `boolean` | false | Make the editor read-only. |
| labels | `Partial<RichTextLabels>` | - | Override toolbar and mention strings. |
| icons | `Partial<Record<RichTextFormat, ReactNode>>` | - | Replace a button's content. The label stays its accessible name. |
| className | `string` | - | Class on the root. |
| classNames | `Partial<Record<Part, string>>` | - | Class per part: `root`, `toolbar`, `button`, `content`, `mentions`, `option`. |
| id | `string` | - | Id of the editable area. |
| aria-label | `string` | - | Accessible name of the editor. |

### RichTextContent

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| value | `string` | - | Stored markdown, rendered as safe HTML. |
| className | `string` | - | Merged with `RICH_TEXT_CLASSES`. |

### RichTextPerson

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| id | `string` | - | Stored in the mention token. |
| name | `string` | - | Shown in the picker and the mention. |
| email | `string \| null` | - | Optional. |
