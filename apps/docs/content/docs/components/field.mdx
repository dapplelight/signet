## Usage

```tsx
import {
  Field,
  FieldControl,
  FieldDescription,
  FieldError,
  FieldLabel,
} from "@dapplelight/signet-ui/components/field"
```

```tsx
<Field errors={errors}>
  <FieldLabel>Email</FieldLabel>
  <FieldControl type="email" />
  <FieldDescription>We send receipts here.</FieldDescription>
  <FieldError />
</Field>
```

## Examples

### Error

<Preview>
  <FieldErrorDemo />

```tsx
import { useState } from "react"
import { Field, FieldControl, FieldDescription, FieldError, FieldLabel } from "@dapplelight/signet-ui/components/field"

export function Demo() {
  const [email, setEmail] = useState("billing@acme")
  return (
    <Field
      className="w-full max-w-sm"
      errors={email.includes(".") ? [] : [{ message: "Enter a full email address" }]}
    >
      <FieldLabel>Billing email</FieldLabel>
      <FieldControl type="email" value={email} onChange={(e) => setEmail(e.target.value)} />
      <FieldDescription>Receipts are sent here.</FieldDescription>
      <FieldError />
    </Field>
  )
}
```

## API Reference

Built on UI SDK's field. Every part takes that primitive's props plus `className`.

### Field

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `errors` | `readonly (string \| { message?: string } \| null \| undefined)[]` | none | Validation errors, such as a TanStack Form field's `state.meta.errors`. Any message marks the field invalid. |
| `invalid` | `boolean` | from `errors` | Force the invalid state. |
| `disabled` | `boolean` | `false` | Disable the field and dim it. |

### FieldControl

Renders Signet's `Input` unless `render` is given. Takes input props.

### FieldError

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `children` | `ReactNode` | first of `errors` | Message to show whenever the field is invalid. |
| `match` | validity flag | none | Show only for one browser validity flag, such as `valueMissing`. |

### FieldLabel, FieldDescription

Text parts; they take `className` and the primitive's props.
