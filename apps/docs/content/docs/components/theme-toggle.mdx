## API Reference

`ThemeToggle`

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `showLabels` | `boolean` | `false` | Show Light, Dark and System beside the icons. Good for a settings page. |
| `className` | `string` | `-` | Merged onto the group. |

`ThemeToggleButton`

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `className` | `string` | `-` | Merged onto the button. It flips light and dark. |

Both need a `ThemeProvider` above them. Labels come from the labels provider. These demos change the theme of this page.
