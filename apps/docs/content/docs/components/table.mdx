## Usage

```tsx

  Table,
  TableBody,
  TableCaption,
  TableCell,
  TableHead,
  TableHeader,
  TableRow,
} from "@dapplelight/signet-ui/components/table"
```

```tsx
<Table>
  <TableHeader>
    <TableRow>
      <TableHead>Invoice</TableHead>
    </TableRow>
  </TableHeader>
  <TableBody>
    <TableRow>
      <TableCell>INV-1042</TableCell>
    </TableRow>
  </TableBody>
</Table>
```

## API Reference

`Table` wraps a `<table>` in a `div`. `TableHeader` is `<thead>`, `TableBody` is `<tbody>`, `TableRow` is `<tr>`, `TableHead` is `<th>`, `TableCell` is `<td>` and `TableCaption` is `<caption>` (shown below the table).

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `className` | `string` | `-` | On every part. Merged over the defaults. |

Every part also takes the native props of its element. For sorting, filtering and pagination see Data Table.
