## Usage

```tsx
import { Label } from "@dapplelight/signet-ui/components/label"
import { Input } from "@dapplelight/signet-ui/components/input"

<Label htmlFor="email">Email</Label>
<Input id="email" />
```

## API Reference

### Label

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `htmlFor` | `string` | none | The id of the control it names. |
| `className` | `string` | none | Merged last. |

Plus every `<label>` prop. It dims when a sibling marked `peer` is disabled. For a label tied to errors and descriptions, use `Field`.
