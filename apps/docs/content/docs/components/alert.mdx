## API Reference

### Alert

| Prop | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| `variant` | `"default" \| "destructive" \| "warning"` | `"default"` | No | Colour of the border, background and icon. |
| `className` | `string` | — | No | Merged last. |

Plus every native [`<div>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/div) attribute. Renders with `role="alert"`. A direct child `svg` is placed at the start and the text indents past it.

### AlertTitle

| Prop | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| `className` | `string` | — | No | Merged last. |

Plus every native [`<h5>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/Heading_Elements) attribute.

### AlertDescription

| Prop | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| `className` | `string` | — | No | Merged last. |

Plus every native [`<div>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/div) attribute.
