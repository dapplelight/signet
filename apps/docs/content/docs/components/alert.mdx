## Usage

```tsx

```

```tsx

  <AlertTitle>Heads up</AlertTitle>
  <AlertDescription>Something worth reading.</AlertDescription>
</Alert>
```

## API Reference

### Alert

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `default` \| `destructive` \| `warning` | `default` | Colour of the border, background and icon. |
| `className` | `string` | - | Merged last. |

Renders a `div` with `role="alert"` and accepts every `div` prop. A direct child `svg` is placed at the start and the text indents past it.

### AlertTitle

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `className` | `string` | - | Merged last. |

Renders an `h5`.

### AlertDescription

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `className` | `string` | - | Merged last. |

Renders a `div`.
