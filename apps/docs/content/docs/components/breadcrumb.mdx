## Usage

```tsx
import {
  Breadcrumb,
  BreadcrumbEllipsis,
  BreadcrumbItem,
  BreadcrumbLink,
  BreadcrumbList,
  BreadcrumbPage,
  BreadcrumbSeparator,
} from "@dapplelight/signet-ui/components/breadcrumb"

<Breadcrumb>
  <BreadcrumbList>
    <BreadcrumbItem><BreadcrumbLink href="/">Home</BreadcrumbLink></BreadcrumbItem>
    <BreadcrumbSeparator />
    <BreadcrumbItem><BreadcrumbPage>Invoices</BreadcrumbPage></BreadcrumbItem>
  </BreadcrumbList>
</Breadcrumb>
```

## API Reference

### Breadcrumb

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `aria-label` | `string` | `"Breadcrumb"` | Name of the nav landmark. |

Renders a `nav`.

### BreadcrumbList, BreadcrumbItem

Render an `ol` and an `li`. Both take `className` and every element prop.

### BreadcrumbLink

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `render` | `ReactElement` | - | Use the router's link element instead of an `a`. Its props are merged in. |
| `className` | `string` | - | Merged last. |

Plus every `a` prop.

### BreadcrumbPage

The current page. A `span` with `aria-current="page"`, not a link.

### BreadcrumbSeparator

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `children` | `ReactNode` | chevron icon | Replaces the separator icon. |

Renders an `li` hidden from assistive tech.

### BreadcrumbEllipsis

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `label` | `string` | `"More"` | Screen reader text. |
