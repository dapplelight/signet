```tsx
<Skeleton className="h-4 w-[250px]" />
```

```tsx
import { Skeleton } from "@dapplelight/signet-ui/components/skeleton"

  return (
    <div className="w-full max-w-md divide-y divide-border-subtle">
      {Array.from({ length: 4 }, (_, i) => (
```

## API Reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `className` | `string` | `-` | Set the size and shape here. Merged over `animate-pulse rounded-xl bg-bg-surface`. |

Plus every native prop of the element.
