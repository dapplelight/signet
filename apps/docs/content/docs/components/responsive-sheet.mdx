```tsx
  )
```

## Usage

```tsx
import { useState } from "react"
import { ResponsiveSheet } from "@dapplelight/signet-ui/components/responsive-sheet"
import { ExpenseForm } from "./expense-form"

const [open, setOpen] = useState(false)

{open && (
  <ResponsiveSheet title="Add expense" onClose={() => setOpen(false)}>
    <ExpenseForm />
  </ResponsiveSheet>
)}
```

It is always open. Mount it only while it should show, so the form inside starts fresh each time.

## Examples

### Editing a row

  <ResponsiveSheetEditDemo />

```tsx
import { useState } from "react"
```

## API Reference

### ResponsiveSheet

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| title | `ReactNode` | - | Sheet title. |
| description | `ReactNode` | - | Optional line under the title. |
| onClose | `() => void` | - | Called on dismiss: swipe, Escape or outside click. |
| children | `ReactNode` | - | The form or content. |
| testId | `string` | - | `data-testid` on the body wrapper, next to `data-sheet` (`"drawer"` or `"dialog"`). |
| desktopQuery | `string` | md breakpoint | Media query where the dialog takes over from the drawer. |
| className | `string` | - | Class on the body wrapper. |
