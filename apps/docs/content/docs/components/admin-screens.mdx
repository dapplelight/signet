## Usage

```tsx
import { AdminScreen, AdminPanel, AdminNav, AdminMain, AdminHeader, AdminToolbar, AdminTable, AdminPager } from "@dapplelight/signet-ui/screens/admin-screens"
```

```tsx
<AdminScreen api={createAdminApi({ baseUrl: "/admin" })} />
```

The demos run on an in-memory `AdminApi`; in an app, use `createAdminApi({ baseUrl })` against signet-server's `adminRoutes`. Parts other than `AdminPanel` must sit inside it.

### AdminRecordSheet

<Preview>
  <AdminRecordSheetDemo />

```tsx
import { Button } from "@dapplelight/signet-ui/components/button"
import { AdminPanel, AdminRecordSheet, type AdminRecordTarget, createAdminApi } from "@dapplelight/signet-ui/screens/admin-screens"
import { useState } from "react"

const api = createAdminApi({ baseUrl: "/admin" })

export function AdminRecordSheetDemo() {
  const [record, setRecord] = useState<AdminRecordTarget>(null)
  return (
    <AdminPanel api={api} defaultTable="orders" record={record} onRecordChange={setRecord}>
      <Button onClick={() => setRecord({ id: "ord_1001" })}>Open order ord_1001</Button>
      <AdminRecordSheet />
    </AdminPanel>
  )
}
```

## API Reference

### AdminScreen

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `api` | `AdminApi` | — | What the panel calls. `createAdminApi` implements it over HTTP. |
| `meta` | `AdminMeta` | — | Metadata you already have; otherwise `api.meta()` is fetched. |
| `table` | `string` | — | The open table (controlled). |
| `defaultTable` | `string` | `first listable table` | Initial table. |
| `onTableChange` | `(table: string) => void` | — | Called when the table changes. |
| `record` | `AdminRecordTarget` | — | The open record (controlled): `{ id }`, `{ id: null }` for a new row, or `null`. |
| `defaultRecord` | `AdminRecordTarget` | `null` | Initial record. |
| `onRecordChange` | `(record: AdminRecordTarget) => void` | — | Called when a record opens or closes. |
| `pageSize` | `number` | `25` | Rows per page. |
| `labels` | `Partial<AdminLabels>` | — | Every string, in English by default. Spread `DEFAULT_ADMIN_LABELS` to translate. |
| `renderCell` | `(args: { value; column; row }) => ReactNode` | — | Replaces a cell's rendering. Return undefined to keep the default. |
| `renderField` | `(args: { column; value; onChange; id }) => ReactNode` | — | Replaces one field's control in the form. |
| `classNames` | `Partial<Record<"nav" \| "main" \| "header" \| "toolbar" \| "table" \| "pager" \| "sheet", string>>` | — | Classes per part. |
| `render` | `ReactElement` | — | Replaces the root element. |

### AdminPanel

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `api` | `AdminApi` | — | What the panel calls. |
| `meta` | `AdminMeta` | — | Metadata you already have. |
| `table, defaultTable, onTableChange` | `string` | — | The open table, controlled or not. |
| `record, defaultRecord, onRecordChange` | `AdminRecordTarget` | — | The open record, controlled or not. |
| `pageSize` | `number` | `25` | Rows per page. |
| `labels` | `Partial<AdminLabels>` | — | Every string. |
| `children` | `ReactNode` | — | The parts, rendered inside a grid. Use `useAdmin()` in a custom part for the state. |

### AdminRecordForm

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `row` | `AdminRow` | — | The row being edited. Absent means create. |
| `onSaved` | `(row: AdminRow) => void` | — | Called with the saved row. |
| `renderField` | `(args: { column; value; onChange; id }) => ReactNode` | — | Replaces one field's control. |
| `className` | `string` | — | Class for the form. |

### AdminAuditTrail

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `table` | `string` | — | Table name of the row. |
| `id` | `string` | — | Row id. |
| `className` | `string` | — | Class for the list. |

### AdminRowActions

| Prop | Type | Default | Description |
| --- | --- | --- | --- |

| `className` | `string` | — | Class for the trigger. |

### AdminRecordSheet

### AdminTable

### AdminNav, AdminMain, AdminHeader, AdminToolbar, AdminPager, AdminFilterButton

| Prop | Type | Default | Description |

| `className` | `string` | — | Merged over the defaults. Except AdminFilterButton, each also takes `render`. |
