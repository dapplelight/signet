## Usage

```tsx
import {
  Markdown,
  MarkdownToc,
  markdownToc,
} from "@dapplelight/signet-ui/components/markdown"

<Markdown>{job.description}</Markdown>
```

Needs the optional peers `react-markdown`, `remark-gfm`, `remark-parse`, `unified` and `github-slugger`.

## API Reference

### Markdown

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| children | `string` | - | The Markdown source. Raw HTML in it is dropped. |
| className | `string` | - | Class on the wrapper. |
| idPrefix | `string` | `"user-content-"` | Prefix for heading ids. Pass the same value to `MarkdownToc`. |
| images | `boolean \| ((src: string) => boolean)` | false | `false` shows alt text only. `true` allows any safe URL. A function decides per URL. |
| headingAnchors | `boolean` | true | Show a `#` link beside each heading. |

### MarkdownToc

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| markdown | `string` | - | The same Markdown given to `Markdown`. |
| maxDepth | `number` | 3 | Deepest heading level listed. |
| idPrefix | `string` | `""` | Must match the `idPrefix` of `Markdown`. |
| title | `string` | `"On this page"` | Heading and accessible name of the nav. |
| activeId | `string` | - | Heading id to mark current with `aria-current`. |
| className | `string` | - | Class on the nav. |

### markdownToc(markdown, options)

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| maxDepth | `number` | 3 | Deepest heading level returned. |
| idPrefix | `string` | `"user-content-"` | Prefix added to every id. Returns `{ id, text, depth }[]`. |
