## Usage

```tsx
import { Tooltip, TooltipContent, TooltipProvider, TooltipTrigger } from "@dapplelight/signet-ui/components/tooltip"
```

```tsx
<TooltipProvider>
  <Tooltip>
    <TooltipTrigger>Hover</TooltipTrigger>
    <TooltipContent>Add to your cart</TooltipContent>
  </Tooltip>
</TooltipProvider>
```

## Examples

### Side

<Preview>
  <TooltipSideDemo />

```tsx
import { Tooltip, TooltipContent, TooltipProvider, TooltipTrigger } from "@dapplelight/signet-ui/components/tooltip"
import { Button } from "@dapplelight/signet-ui/components/button"

export function Demo() {
  return (
    <TooltipProvider>
      <div className="flex gap-2">
        {(["top", "right", "bottom", "left"] as const).map((side) => (
          <Tooltip key={side}>
            <TooltipTrigger asChild>
              <Button variant="outline" className="capitalize">{side}</Button>
            </TooltipTrigger>
            <TooltipContent side={side}>Shown on the {side}</TooltipContent>
          </Tooltip>
        ))}
      </div>
    </TooltipProvider>
  )
}
```

## API Reference

`TooltipProvider`

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `delayDuration` | `number` | `300` | Milliseconds before a tooltip opens. |
| `skipDelayDuration` | `number` | `300` | Radix default: window in which moving to another tooltip skips the delay. |

`Tooltip` is the Radix root (`open`, `defaultOpen`, `onOpenChange`, and `delayDuration` to override the provider's for one tooltip). `TooltipTrigger` is the Radix trigger (use `asChild` to wrap your own element).

`TooltipContent`

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `side` | `"top" \| "right" \| "bottom" \| "left"` | `"top"` | Preferred side. |
| `align` | `"start" \| "center" \| "end"` | `"center"` | Alignment against the trigger. |
| `sideOffset` | `number` | `4` | Gap from the trigger in px. |
| `className` | `string` | `-` | Merged over the defaults. |

The rest are Radix tooltip content props.
