## API Reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `items` | `StatItem[]` | `-` | The stats. Labels must be unique (they are the keys). |
| `isDesktop` | `boolean` | follows the `md` breakpoint | Force the grid (`true`) or the stacked rows (`false`). |
| `className` | `string` | `-` | Merged onto the wrapper. |

`StatItem`

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `label` | `string` | `-` | Caption. |
| `value` | `ReactNode` | `-` | The headline number. |
| `meta` | `ReactNode` | `-` | A line under it. |
| `tone` | `"good" \| "warn" \| "muted"` | `"muted"` | Colours the meta line. Never red, which means destructive. |

Under the privacy mask, percentages in string values and meta lines show as masked dots.
