## Usage

```tsx
import { DataGrid } from "@dapplelight/signet-ui/components/data-grid"
import { invoices } from "./invoices"
import { save } from "./actions"

<DataGrid
  aria-label="Invoices"
  columns={[{ id: "customer", header: "Customer" }]}
  rows={invoices}
  getRowId={(row) => row.id}
  onChange={save}
/>
```

## API Reference

### DataGrid

Click a header to sort, drag its edge to resize. Rows are virtualised and one line tall, and the grid has no pagination. Arrow keys move, Enter edits, and ranges copy and paste as TSV.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `columns` | `DataGridColumn<T>[]` | required | Column definitions, see below. |
| `rows` | `T[]` | required | The data. Apply saved changes back to it. |
| `getRowId` | `(row: T, index: number) => string` | required | Stable id for each row. |
| `onChange` | `(changes: DataGridChange<T>[]) => Promise<DataGridFailure[] \| undefined> \| DataGridFailure[] \| undefined` | none | Edits, pastes and clears, as a batch. The grid shows new values at once; a throw reverts them with an error on each cell, and returned failures do so for just those cells. |
| `selectable` | `boolean` | `false` | Adds a checkbox column and Shift+Space row selection. |
| `selectedRowIds` | `readonly string[]` | none | Controlled selection. |
| `onSelectedRowIdsChange` | `(ids: string[]) => void` | none | Called when selection changes. |
| `rowHeight` | `number` | `36` | Row height in px. |
| `height` | `number \| string` | `480` | Height of the scrolling body. |
| `overscan` | `number` | `8` | Extra rows rendered outside the viewport. |
| `aria-label` | `string` | none | Accessible name. |
| `aria-labelledby` | `string` | none | Id of the element that names the grid. |
| `labels` | `Partial<DataGridLabels>` | `DEFAULT_DATA_GRID_LABELS` | Override the grid's strings. |
| `className` | `string` | none | Class for the root. |
| `classNames` | `Partial<Record<"root" \| "table" \| "header" \| "headerCell" \| "row" \| "cell" \| "editor" \| "error", string>>` | `{}` | Class per part. |

### DataGridColumn

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `id` | `keyof T` | required | The row key this column reads and writes. |
| `header` | `string` | required | Header text. |
| `type` | `"text" \| "number" \| "select" \| "date" \| "checkbox"` | `"text"` | Editor and paste parsing. Dates are `YYYY-MM-DD` strings. |
| `options` | `{ value: string; label: string }[]` | none | Choices for `type: "select"`. |
| `editable` | `boolean` | `true` | Allow editing. |
| `sortable` | `boolean` | `true` | Allow sorting. |
| `width` | `number` | `160` | Starting width in px. |
| `minWidth` | `number` | `40` | Smallest width when resizing. |
| `format` | `(value: unknown, row: T) => ReactNode` | none | How the value shows when not editing. |
| `parse` | `(text: string, row: T) => { value: unknown } \| { error: string }` | by `type` | Text (typed or pasted) to a value. |
| `validate` | `(value: unknown, row: T) => string \| undefined` | none | Return a message to refuse a value before it is saved. |
