## Examples

### Filtering a list

<Preview>
  <SearchInputFilterDemo />

```tsx
const customers = ["Acme Corp", "Globex", "Initech", "Umbrella Labs", "Hooli", "Stark Industries"]

export function CustomerFilter() {
  const [q, setQ] = useState("")
  const hits = customers.filter((c) => c.toLowerCase().includes(q.toLowerCase()))
  return (
    <>
      <SearchInput value={q} onChange={(e) => setQ(e.target.value)} aria-label="Filter customers" />
      <ul>{hits.map((c) => <li key={c}>{c}</li>)}</ul>
    </>
  )
}
```

</Preview>

## API Reference

### SearchInput

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| containerClassName | `string` | - | Class on the outer box that holds the icon and input. |
| className | `string` | - | Class on the `input`. |
| ...props | `InputHTMLAttributes` | - | Everything an `input` takes except `type`: `value`, `onChange`, `placeholder`, `disabled`. Forwards its ref to the input. |
