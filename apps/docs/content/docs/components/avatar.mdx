## API Reference

### Avatar

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `sm` \| `default` \| `lg` | `default` | 24px, 32px or 40px. |
| `className` | `string` | - | Merged last. |

### AvatarImage

A real `img` the browser can fetch before hydration. Takes every `img` prop. The fallback shows until it loads, or if it fails.

### AvatarFallback

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `className` | `string` | - | Merged last. |

### initials

`initials(name: string): string` turns `"Ada Lovelace"` into `"AL"` and `"grace"` into `"G"`. At most two letters.

`avatarVariants` is exported too, for styling your own element like an avatar.
