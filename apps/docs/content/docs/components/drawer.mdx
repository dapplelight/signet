## Usage

```tsx
import {
  Drawer,
  DrawerClose,
  DrawerContent,
  DrawerDescription,
  DrawerFooter,
  DrawerHeader,
  DrawerTitle,
  DrawerTrigger,
} from "@dapplelight/signet-ui/components/drawer"
```

```tsx
<Drawer>
  <DrawerTrigger render={<Button variant="outline" />}>Open</DrawerTrigger>
  <DrawerContent>
    <DrawerHeader>
      <DrawerTitle>Title</DrawerTitle>
      <DrawerDescription>Description</DrawerDescription>
    </DrawerHeader>
    <DrawerFooter>
      <DrawerClose render={<Button variant="outline" />}>Close</DrawerClose>
    </DrawerFooter>
  </DrawerContent>
</Drawer>
```

## API Reference

Built on Base UI's Drawer. `DrawerTrigger`, `DrawerClose`, `DrawerPortal`, `DrawerOverlay`, `DrawerTitle` and `DrawerDescription` take that primitive's props.

### Drawer

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `swipeDirection` | `"down" \| "up" \| "left" \| "right"` | `"down"` | The edge it opens from, and the direction that dismisses it. |
| `modal` | `boolean` | `true` | Show the overlay and block the page behind. |
| `showSwipeHandle` | `boolean` | `false` | Show a grab handle. |
| `snapPoints` | `number[]` | none | Heights the drawer can rest at. |
| `open` | `boolean` | none | Controlled open state. |
| `defaultOpen` | `boolean` | `false` | Starting state when uncontrolled. |
| `onOpenChange` | `(open: boolean) => void` | none | Called when the drawer opens or closes. |

### DrawerContent

Renders the portal, overlay and popup. Takes the popup's props and `className`.
