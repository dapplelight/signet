## API Reference

| Prop | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| `variant` | `"default" \| "outline" \| "secondary" \| "ghost" \| "destructive" \| "link"` | `"default"` | No | Colour and emphasis. |
| `size` | `"default" \| "xs" \| "sm" \| "lg" \| "touch" \| "icon" \| "icon-xs" \| "icon-sm" \| "icon-lg" \| "icon-touch"` | `"default"` | No | Height and padding. `touch` sizes are 44px for phones. Icon-only sizes need `aria-label`. |
| `className` | `string` | — | No | Merged last. |

Plus every native [`<button>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/button) attribute.
