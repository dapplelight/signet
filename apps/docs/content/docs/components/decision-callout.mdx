## Usage

```tsx
import { DecisionCallout, DecisionCalloutReason, DecisionCalloutTitle } from "@dapplelight/signet-ui/components/decision-callout"

<TimelineItem status="complete">
  <TimelineMarker />
  <TimelineTitle>Build</TimelineTitle>
  <DecisionCallout>
    <DecisionCalloutTitle>Ran 42 affected tests instead of the full suite</DecisionCalloutTitle>
    <DecisionCalloutReason>The diff touches 3 of 61 packages; 18 s instead of 6 min.</DecisionCalloutReason>
  </DecisionCallout>
</TimelineItem>
```

It sits in the text column of a [Timeline](/docs/components/timeline) item, under the step's own text. It is a plain `div`, not an [Alert](/docs/components/alert), so screen readers do not announce each decision as it appears. Long text wraps. The reason line uses `text-text-secondary`, because `text-text-muted` does not reach 4.5:1 on the tint in every theme.

## Customising

1. **Tokens.** The box is tinted with `accent-primary-subtle`, so it follows your primary colour.
2. **Props.** Children only: a title line and a reason line. Add an icon from lucide inside the title if you want one.
3. **`className`.** Every part takes one, merged over the defaults.
4. **Parts.** `DecisionCallout`, `DecisionCalloutTitle` and `DecisionCalloutReason` each carry a `data-slot` (`decision-callout`, `decision-callout-title`, `decision-callout-reason`) to target from CSS.
5. **Own the source.** `signet add decision-callout` copies the file into your project.

## API Reference

| Part | Element | Default classes |
| --- | --- | --- |
| `DecisionCallout` | `div` | `col-start-2 mt-2 rounded-md bg-accent-primary-subtle px-3 py-2` |
| `DecisionCalloutTitle` | `p` | `text-sm font-semibold text-text-primary` |
| `DecisionCalloutReason` | `p` | `text-xs text-text-secondary tabular-nums` |

Each takes `className` and every native prop of its element.
