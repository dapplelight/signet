## API Reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `aria-label` | `string` | `"Loading"` | What screen readers hear. It has `role="status"`. |
| `className` | `string` | `size-4 text-text-muted` | Size and colour. The spin stops under `prefers-reduced-motion`. |

Plus every native `<svg>` prop.
