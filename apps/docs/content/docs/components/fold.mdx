The body is rendered by [Markdown](/docs/components/markdown), so Fold needs its optional peers (`react-markdown`, `remark-gfm`, `remark-parse`, `unified`, `github-slugger`). That is why it is imported from `components/fold` and not the barrel.

## Usage

```tsx
import { Fold } from "@dapplelight/signet-ui/components/fold"

<Fold title="Builder notes" detail="12 lines, written by the builder">
  {markdown}
</Fold>
```

The toggle is a real button: Enter and Space work, `aria-expanded` announces open or closed, and `aria-controls` points at the text. The text is capped at about 66 characters wide.

## Customising

- **Tokens:** it uses theme utilities only, so a theme change restyles it.
- **Words:** `showMoreLabel` / `showLessLabel`, or `showMore` / `showLess` once for the app through `LabelsProvider`.
- **Classes and state:** `className`, `classNames` per part (`header`, `title`, `detail`, `toggle`, `body`, `markdown`) and `data-state="open|closed"`.
- **Parts:** `FoldRoot`, `FoldHeader`, `FoldTitle`, `FoldDetail`, `FoldToggle`, `FoldBody` to build your own row (a badge in the header, plain text in the body).
- **Own the code:** `signet add fold` copies the file in.

## API Reference

### Fold

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| title | `ReactNode` | - | The row's title. |
| detail | `ReactNode` | - | Muted text beside the title. |
| children | `string` | - | The long text, as Markdown. |
| open | `boolean` | - | Controlled state. |
| defaultOpen | `boolean` | `false` | Start open. |
| onOpenChange | `(open: boolean) => void` | - | Called when the link is used. |
| showMoreLabel | `string` | `"Show more"` | Link text while closed. |
| showLessLabel | `string` | `"Show less"` | Link text while open. |
| markdown | `Omit<MarkdownProps, "children">` | - | Passed to the Markdown renderer. |
| classNames | `{ header?; title?; detail?; toggle?; body?; markdown? }` | - | Class per part. |
