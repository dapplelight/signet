## Usage

`recharts` is an optional peer, so this screen has its own export path and is never in the barrel. Install `recharts` first.

```tsx
import { SubscriptionCharts } from "@dapplelight/signet-ui/screens/subscription-charts"
```

`data` is signet-db's `charts.metrics(...)` result (or the JSON of `GET /charts`); filter changes go out through `onFilterChange`.

```tsx
import { useState } from "react"
import { SubscriptionCharts, type ChartFilterView } from "@dapplelight/signet-ui/screens/subscription-charts"
import { data } from "./charts"

const [filter, setFilter] = useState<ChartFilterView>({ from: data.from, to: data.to })

<SubscriptionCharts data={data} filter={filter} onFilterChange={setFilter} />
```

## API Reference

### SubscriptionCharts

Also accepts `section` props except `children`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `data` | `ChartResultView \| null` | required | Daily series and summary; null shows the empty state. |
| `filter` | `ChartFilterView` | required | Dates, `store`, `plan`, `country`, `offering` and `audience`. |
| `onFilterChange` | `(filter: ChartFilterView) => void` | required | Called when a filter changes. |
| `options` | `{ stores?, plans?, countries?, offerings?: readonly string[] }` | `{}` | Values offered in each filter's select. |
| `audiences` | `readonly ChartAudienceView[]` | - | Saved audiences to pick. |
| `onSaveAudience` | `(name: string, filter) => unknown` | - | Save the current filters as an audience. |
| `csvHref` | `string` | - | Link to `GET /charts/csv` with the current query; shows Export CSV. |
| `currency` | `string` | first in data | The currency the revenue chart shows. |
| `labels` | `Partial<ChartLabels>` | `DEFAULT_CHART_LABELS` | Override any string. |
