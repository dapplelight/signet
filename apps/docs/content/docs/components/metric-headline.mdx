## API Reference

### MetricHeadline

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| result | `{ current: number; previous: number \| null }` | - | This period and the one before it. |
| label | `string` | - | The metric's name as the sentence starts it. |
| period | `string` | `"this week"` | Appended to the sentence. |
| flatWithin | `number` | 1 | Changes under this percent read as flat. |
| goodWhen | `"up" \| "down"` | `"up"` | Which direction is good news. |
| copy | `Partial<MetricHeadlineCopy>` | - | Override the `up`, `down`, `flat`, `new` and `trend` strings. |
| format | `(n: number) => string` | locale number format | Formats the value. |
| classNames | `{ value?; sentence?; trend? }` | - | Class per part. |
| children | `ReactNode` | - | Extra content under the sentence. |

### metricTrend(result, options)

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| returns | `{ direction; tone; percent }` | - | The rule behind the headline, for an app that renders its own. |

### metricSentence(result, options)

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| returns | `string` | - | The plain sentence, for aria-labels, notifications and agents. |
