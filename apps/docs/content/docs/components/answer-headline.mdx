## API Reference

### AnswerHeadline

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `headline` | `AnswerHeadlineData` | required | The question, sentence, optional detail and tone. |
| `renderValue` | `(value: number) => ReactNode` | locale number, `••••••` when masked | Renders each `{ value }` segment. A custom one must mask itself. |
| `className` | `string` | - | Merged last. |
| `children` | `ReactNode` | - | Extra controls under the sentence, such as period pills or a link. |

### AnswerHeadlineData

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `question` | `string` | required | Small muted line above the sentence. Also the section's `aria-label`. |
| `sentence` | `AnswerSegment[]` | required | Text, or `{ value: number }` rendered bold by `renderValue`. |
| `detail` | `AnswerSegment[]` | - | Optional supporting line. |
| `tone` | `neutral` \| `good` \| `warn` | required | `warn` renders amber. Never red, which means destructive. |

Under the privacy mask, percentages in the text become `••%`.

### answerText

`answerText(segments, format?)` returns the plain text of a sentence for aria-labels, notifications and tests. `format` defaults to the locale number format.
