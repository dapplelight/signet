## API Reference

### EmptyState

Fills at least 60% of the viewport height, centred.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `title` | `string` | required | The headline. |
| `description` | `string` | none | Supporting text. |
| `icon` | `ReactNode` | none | Shown above the title. |
| `action` | `ReactNode` | none | Shown below, usually a Button. |
