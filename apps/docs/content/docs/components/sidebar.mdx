## Usage

```tsx
import {
  Sidebar,
  SidebarContent,
  SidebarFooter,
  SidebarGroup,
  SidebarGroupLabel,
  SidebarHeader,
  SidebarInset,
  SidebarMenu,
  SidebarMenuButton,
  SidebarMenuItem,
  SidebarProvider,
  SidebarTrigger,
  useSidebar,
} from "@dapplelight/signet-ui/components/sidebar"

<SidebarProvider>
  <Sidebar>
    <SidebarContent />
  </Sidebar>
  <SidebarInset>
    <SidebarTrigger />
  </SidebarInset>
</SidebarProvider>
```

Press `Ctrl+B` or `Cmd+B` to toggle. The demos turn the shortcut off so it does not clash with the page.

## API Reference

### SidebarProvider

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| defaultOpen | `boolean` | true | Initial desktop state. |
| open | `boolean` | - | Controlled desktop state. |
| onOpenChange | `(open: boolean) => void` | - | Called when it expands or collapses. |
| shortcut | `string \| null` | `"mod+b"` | Key that toggles the sidebar. `null` turns it off. |
| desktopQuery | `string` | md breakpoint | Media query where the panel takes over from the drawer. |
| className | `string` | - | Class on the wrapper. |

### Sidebar

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| collapsible | `"icon" \| "offcanvas"` | `"icon"` | Collapse to an icon strip, or hide fully. |
| side | `"left" \| "right"` | `"left"` | Which edge it sits on. |
| aria-label | `string` | `"Sidebar"` | Accessible name. |
| mobileDescription | `string` | `"Navigation"` | Screen-reader description of the phone drawer. |
| mobileClassName | `string` | - | Class on the phone drawer surface. |

### SidebarTrigger

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| label | `string` | `"Toggle sidebar"` | Screen-reader label. |
| children | `ReactNode` | panel icon | Replace the icon. |

### SidebarMenuButton

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| isActive | `boolean` | false | Marks the current page: `aria-current` and active style. |
| render | `ReactElement` | - | Render a link or router link instead of a button. |

### Layout parts

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| SidebarInset | `main` | - | The content beside the sidebar. |
| SidebarHeader / SidebarContent / SidebarFooter | `div` | - | Sections of the panel. |
| SidebarGroup / SidebarGroupLabel | `div` | - | A labelled group of items. |
| SidebarMenu / SidebarMenuItem | `ul / li` | - | The list of items. |

### useSidebar

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| returns | `{ isMobile, open, setOpen, openMobile, setOpenMobile, toggle, panelId }` | - | State and controls. Throws outside a `SidebarProvider`. |
