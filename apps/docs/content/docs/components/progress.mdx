## Usage

```tsx
import {
  Progress,
  ProgressLabel,
  ProgressValue,
} from "@dapplelight/signet-ui/components/progress"
```

```tsx
<Progress value={64} aria-label="Storage used" />
```

Built on Base UI's Progress, so the root takes its props.

## API Reference

### Progress

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| value | `number \| null` | - | Current value. `null` means indeterminate. |
| min | `number` | 0 | Lowest value. |
| max | `number` | 100 | Highest value. |
| format | `Intl.NumberFormatOptions` | - | How the value is formatted. |
| getAriaValueText | `(formatted, value) => string` | - | Accessible value text. |
| className | `string` | - | Class on the root. |
| children | `ReactNode` | - | `ProgressLabel` and `ProgressValue`, shown above the bar. |

### ProgressLabel

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| className | `string` | - | Class on the label. |

### ProgressValue

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| children | `(formatted, value) => ReactNode` | - | Custom text for the value. Defaults to the formatted percentage. |
| className | `string` | - | Class on the value. |

### ProgressTrack / ProgressIndicator

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| className | `string` | - | The bar and its fill, already rendered by `Progress`. Export them to build your own. |
