## Usage

```tsx
import { RadioGroup, RadioGroupItem } from "@dapplelight/signet-ui/components/radio-group"
```

```tsx
<RadioGroup defaultValue="team" aria-label="Plan">
  <label className="flex items-center gap-2">
    <RadioGroupItem value="team" />
    Team
  </label>
</RadioGroup>
```

Built on UI SDK's radio: one tab stop, and arrow keys move and check.

## API Reference

### RadioGroup

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| value | `string \| null` | - | Controlled selected value. `null` selects nothing. |
| defaultValue | `string \| null` | - | Initial value when uncontrolled. |
| onValueChange | `(value: string \| null, details) => void` | - | Called when the selection changes. |
| name | `string` | - | Form field name for the hidden native radio. |
| disabled | `boolean` | false | Disable every item. |
| readOnly | `boolean` | false | Show the value without allowing changes. |
| required | `boolean` | false | Require a choice in a form. |
| form | `string` | - | `id` of a form to attach the hidden radio to. |
| loop | `boolean` | true | Whether arrow keys wrap from the last item to the first. |
| controller | `RadioGroupController` | - | Read and drive the group from outside (`createRadioGroupController()`). |
| className | `string` | - | Merged with `grid gap-2`. |

### RadioGroupItem

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| value | `string` | - | This option's value. |
| disabled | `boolean` | false | Disable this option. |
| className | `string` | - | Class on the radio. Wrap it with its text in a `label`, or give it `aria-label`. |
