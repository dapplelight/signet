```bash
npm i @dapplelight/signet-ui @dapplelight/signet-tokens
```

## Quick start

```css title="app.css"
@import "tailwindcss";
@import "@dapplelight/signet-tokens/editorial.css";
@import "@dapplelight/signet-tokens/base.css";
/* Tailwind does not scan node_modules; the kit's class names must be seen. */
@source "../node_modules/@dapplelight/signet-ui/dist";
```

```tsx
import { Button } from "@dapplelight/signet-ui/components/button"
import { Card } from "@dapplelight/signet-ui/components/card"

export function Invoice() {
  return (
    <Card>
      <Button>Pay now</Button>
    </Card>
  )
}
```

The barrel works too: `import { Button, Card } from "@dapplelight/signet-ui"`. Swap the theme file and every component changes.
