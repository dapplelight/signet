## Usage

```tsx
import { AuthScreen } from "@dapplelight/signet-ui/screens/auth-screens"

export function SignIn() {
  return (
    <AuthScreen
      onRequestCode={({ channel, to, mode }) =>
        fetch("/api/auth/code", { method: "POST", body: JSON.stringify({ channel, to, mode }) })
      }
      onVerify={({ to, code }) =>
        fetch("/api/auth/verify", { method: "POST", body: JSON.stringify({ to, code }) })
      }
    />
  )
}
```

Every screen is plain data in, callbacks out: no fetch or router inside. A callback that returns a Promise keeps its button pending; one that throws shows its message. Each module also exports `DEFAULT_*_LABELS` and takes a `labels` prop to translate or reword any string.

## API

Each module is its own path, `@dapplelight/signet-ui/screens/<name>`. Shapes of the data props match `signet-server` and `signet-db` results (or their JSON).

### cost-dashboard

AI cost for the admin: a spend-over-time chart with what the cache saved, spend by model, top spenders (subject hashes, exactly as the server gives them), and global cap usage bars. Needs the optional peer `recharts`, so it is never in the barrel. Money is millionths of a USD; anything above zero but under one cent shows "<$0.01". The caps bar is the primary colour under 80%, amber from 80%, red at 100% and over, and always shows its percent as text; a null cap reads "No cap".

Feed it the JSON of signet-server's `observabilityAdminRoutes` (`series`, `models`, `top`) and, for the caps card, signet-db's `usage("global")`. Pass `fetcher(days)` and the screen loads, reloads on a new range and retries itself; or pass `data`, `loading`, `error`, `onRetry` and `onDaysChange` and own the state.

```tsx
import { CostDashboard } from "@dapplelight/signet-ui/screens/cost-dashboard"

const get = (path: string, days: number) =>
  fetch(`/api/admin/observability/cost/${path}?days=${days}`).then((r) => r.json())

<CostDashboard
  fetcher={async (days) => {
    const [s, m, t, caps] = await Promise.all([
      get("series", days), get("by-model", days), get("top", days), fetch("/api/admin/ai-caps").then((r) => r.json()),
    ])
    return { series: s.series, models: m.models, top: t.top, caps }
  }}
/>
```

| Export | What it does |
| --- | --- |
| `CostDashboard` | Range select, spend / cache-saved / top-model tiles, and the four cards. Root `data-slot="cost-dashboard"`; cards `chart-spend`, `cost-models`, `cost-top`, `cost-caps`; rows carry `data-model`, `data-subject` or `data-period`. |
| `DEFAULT_COST_LABELS` | Default strings, plus `money(units)` (USD). |
| Types | `CostDashboardData`, `CostSeriesRow`, `CostModelRow`, `CostSubjectRow`, `CostCapUsage`, `CostLabels`, `CostDashboardProps`. |

## Examples

### Account page

```tsx
import { ApiKeysManager, ProfileCard, SessionsList } from "@dapplelight/signet-ui/screens/account-screens"

export function AccountPage({ me, sessions, keys }: AccountData) {
  return (
    <>
      <ProfileCard profile={me} onSave={({ name }) => api.profile.update({ name })} />
      <SessionsList
        sessions={sessions}
        onRevoke={(s) => api.sessions.revoke(s.id)}
        onRevokeOthers={() => api.sessions.revokeOthers()}
      />
      <ApiKeysManager
        keys={keys}
        onCreate={({ name }) => api.keys.create({ name })} // returns { token }, shown once
        onRevoke={(k) => api.keys.revoke(k.id)}
      />
    </>
  )
}
```

### Billing page

```tsx
import { BillingScreen, plansFromEntitlements } from "@dapplelight/signet-ui/screens/billing-screens"

export function Billing({ subscription, usage, invoices }: BillingData) {
  return (
    <BillingScreen
      plans={[
        { key: "free", name: "Free" },
        { key: "pro", name: "Pro", badge: "Popular", prices: { month: { amount: 49900, currency: "INR" } } },
      ]}
      subscription={subscription}
      usage={usage}
      invoices={invoices}
      onSubscribe={(plan, interval) => startCheckout(plan.key, interval)}
      onManage={() => openCustomerPortal()}
    />
  )
}
```

Use `plansFromEntitlements` to build `plans` from your `definePlans` object. See `BillingPrice` and `BillingInterval` for the exact price shape.

### Admin panel for every table

```tsx
import { AdminScreen, createAdminApi } from "@dapplelight/signet-ui/screens/admin-screens"

const api = createAdminApi({ baseUrl: "/admin" })

export function Admin() {
  return <AdminScreen api={api} pageSize={50} />
}
```

`createAdminApi` options: `baseUrl` (default `"/admin"`), `fetch`, and `headers` (a function returning extra headers). Cookies are sent.

### Notification inbox and preferences

```tsx
import { NotificationInbox, NotificationPreferences } from "@dapplelight/signet-ui/screens/notification-screens"

export function Notifications({ items, prefs }: NotificationData) {
  return (
    <>
      <NotificationInbox
        items={items}
        onMarkRead={(ids) => api.inbox.markRead(ids)}
        onMarkAllRead={() => api.inbox.markAllRead()}
        onArchive={(item) => api.inbox.archive(item.id)}
      />
      <NotificationPreferences
        categories={[
          { id: "invoices", label: "Invoices", description: "Sent, paid and overdue" },
          { id: "security", label: "Security", required: true },
        ]}
        defaultValue={prefs}
        onToggle={(change) => api.prefs.update(change)}
      />
    </>
  )
}
```

### Live presence on a record

```tsx
import { createRealtimeClient, useRecordChanges, usePresence } from "@dapplelight/signet-ui/hooks/use-channel"
import { AvatarStack, RecordChangedBanner } from "@dapplelight/signet-ui/screens/realtime-screens"

const live = createRealtimeClient({ url: "/realtime" })

export function InvoiceHeader({ id, me }: { id: string; me: string }) {
  const channel = `record:invoices:${id}`
  const members = usePresence(live, channel)
  const { changed, dismiss } = useRecordChanges(live, channel, { selfId: me })
  return (
    <>
      <AvatarStack members={members} selfId={me} />
      <RecordChangedBanner changed={changed} onReload={() => location.reload()} onDismiss={dismiss} />
    </>
  )
}
```
