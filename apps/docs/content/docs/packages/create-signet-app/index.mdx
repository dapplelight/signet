<AgentPrompt title="Scaffold a Signet app">
Create a new app with `npx create-signet-app@latest my-app --starter full`, then run `cd my-app`, `npm install` and `npm run dev`. Use `--platform api` for a backend only, `--platform web` for a frontend only, `--starter mobile` for an Expo app and its API, or another starter such as `--starter saas` for a different mix.

Add the Signet MCP server first so you can look up components, themes and conventions: `claude mcp add signet -- bunx @dapplelight/signet-mcp`.

Build every screen from `@dapplelight/signet-ui` components and `@dapplelight/signet-tokens` themes, and use the generated typed API client in src/lib/api.ts. Do not hand-roll buttons, inputs or fetch wrappers. Run lint, typecheck and tests before you finish.
</AgentPrompt>
