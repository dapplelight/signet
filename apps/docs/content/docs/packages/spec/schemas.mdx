## Usage

```ts
import codes from "@dapplelight/signet-spec/schemas/error-codes.json" with { type: "json" }

codes.codes.NOT_FOUND // 404
```

The files are generated from the Zod modules by `bun run gen` in `packages/spec`, and the same bytes are served at `/spec/v1/`.

## API

| Import | What it is |
| --- | --- |
| `@dapplelight/signet-spec/schemas/error-envelope.schema.json` | JSON Schema 2020-12 for the error envelope |
| `@dapplelight/signet-spec/schemas/error-codes.json` | `{ specVersion, codes }`: each code and its HTTP status |
| `@dapplelight/signet-spec/schemas/analytics-ingest-request.schema.json` | JSON Schema 2020-12 for the ingest POST body |
| `@dapplelight/signet-spec/schemas/analytics-ingest-response.schema.json` | JSON Schema 2020-12 for the 202 reply |
| `@dapplelight/signet-spec/schemas/tracked-event.schema.json` | JSON Schema 2020-12 for one analytics event |
| `@dapplelight/signet-spec/schemas/webhook-delivery.schema.json` | JSON Schema 2020-12 for a webhook's headers, body and outbox message |
