---

```bash
bun add @dapplelight/signet-spec
```

`zod` (4.2 or later) is a peer dependency.

## Quick start

```ts
import { errorEnvelopeSchema } from "@dapplelight/signet-spec/error"

const res = await fetch("/api/orders", { method: "POST", body: "{}" })
if (!res.ok) {
  const parsed = errorEnvelopeSchema.safeParse(await res.json())
  if (parsed.success) console.log(parsed.data.code, parsed.data.error)
}
```

The Zod schemas in `src/error.ts` are the source of truth. The JSON files are generated from them, and a test fails when they drift.

## Files

| File | What it is |
| --- | --- |
| [error-envelope.schema.json](/spec/v1/error-envelope.schema.json) | JSON Schema 2020-12 for the body of every failed response. |
| [error-codes.json](/spec/v1/error-codes.json) | Every error code and its default HTTP status. |
| [analytics-ingest-request.schema.json](/spec/v1/analytics-ingest-request.schema.json) | Body of POST to the analytics ingest route. |
| [analytics-ingest-response.schema.json](/spec/v1/analytics-ingest-response.schema.json) | Body of its 202 reply. |
| [tracked-event.schema.json](/spec/v1/tracked-event.schema.json) | One stored analytics event. |
| [webhook-delivery.schema.json](/spec/v1/webhook-delivery.schema.json) | Webhook body, signed headers and outbox message. |

Files under /spec/v1/ never change shape. A breaking change ships as v2 alongside.

Every file carries `"specVersion": "v1"`. The same files ship in the package under `@dapplelight/signet-spec/schemas/`.

## Error codes
