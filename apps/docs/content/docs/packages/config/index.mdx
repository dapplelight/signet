
## Quick start

```json title="biome.json"
{
  "$schema": "https://biomejs.dev/schemas/2.5.14/schema.json",
  "extends": ["@dapplelight/signet-config/biome"],
  "files": { "includes": ["**", "!**/dist"] }
}
```

```json title="tsconfig.json"
{
  "extends": "@dapplelight/signet-config/tsconfig/react.json",
  "include": ["src"]
}
```

```yaml title=".github/workflows/ci.yml"
name: ci
on: [pull_request]
jobs:
  ci:
    uses: dapplelight/signet/.github/workflows/ci-bun.yml@main
```

The CI workflow ships in the Signet repo, not the npm package. See [Biome](/docs/packages/config/biome#ci-bunyml).
