```bash
npm i @dapplelight/signet-tokens
```

## Quick start

```css
@import "tailwindcss";
@import "@dapplelight/signet-tokens/editorial.css";
@import "@dapplelight/signet-tokens/base.css";
```

Add the `dark` class on `<html>` for dark mode.
