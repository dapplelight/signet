<Tabs items={["npm", "pnpm", "bun"]}>
<Tab value="npm">

```bash
npx create-signet-app@latest my-app --template full
cd my-app
npm install
npm run dev
```

</Tab>
<Tab value="pnpm">

```bash
pnpm create signet-app my-app --template full
cd my-app
pnpm install
pnpm run dev
```

</Tab>
<Tab value="bun">

```bash
bunx create-signet-app my-app --template full
cd my-app
bun install
bun run dev
```

</Tab>
</Tabs>

<Steps>
<Step>

### Scaffold

The first command above makes `my-app` with the `editorial` theme. The directory must not exist or be empty.

</Step>
<Step>

### Install and run

`install`, then `run dev`. The API and Vite start together.

</Step>
<Step>

### Open the app

Open `http://localhost:5173`. Sign in with any phone number; the code prints in your terminal.

</Step>
<Step>

### Make your first edit

Change the title. The page reloads on save.

```tsx title="src/routes/_app/index.tsx"
<CardTitle>Welcome to my app</CardTitle>
```

</Step>
</Steps>
