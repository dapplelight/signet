Signet is a design system and backend kit for React apps. Your app holds only its own business logic.

Vite + React + Tailwind v4 on the front, Hono on Cloudflare Workers behind.

- Install packages to get updates.
- Run `signet add` to copy source you own.

## How it fits

| Layer | Packages | You get |
| --- | --- | --- |
| Frontend | `@dapplelight/signet-ui`, `@dapplelight/signet-tokens`, `@dapplelight/signet-lib` | Components, themes, API client, forms |
| Backend | `@dapplelight/signet-server`, `@dapplelight/signet-db`, `@dapplelight/signet-payments`, `@dapplelight/signet-ai` | Auth, middleware, tables, billing, models |
| Tooling | `create-signet-app`, `@dapplelight/signet-cli`, `@dapplelight/signet-mcp`, `@dapplelight/signet-config`, `@dapplelight/signet-test` | Scaffold, copy-in, agents, presets, fakes |

```tsx title="src/routes/index.tsx"
import { createApiClient } from "@dapplelight/signet-lib/api"
import { Button } from "@dapplelight/signet-ui/components/button"
import { useState } from "react"

const api = createApiClient({ baseUrl: "/api" })

export function Home() {
  const [text, setText] = useState("Say hello")
  const load = async () => setText((await api.get<{ text: string }>("/hello")).text)
  return <Button onClick={load}>{text}</Button>
}
```

```ts title="api/index.ts"
import { errorHandler } from "@dapplelight/signet-server/http"
import { requestId, secureHeaders } from "@dapplelight/signet-server/middleware"
import { Hono } from "hono"

const app = new Hono()
app.use(requestId(), secureHeaders())
app.onError(errorHandler({ isProduction: true }))
app.get("/api/hello", (c) => c.json({ text: "Hello from Workers" }))

export default app
```

## 60-second start

<Tabs items={["npm", "pnpm", "bun"]}>
<Tab value="npm">

```bash
npx create-signet-app@latest my-app --template full
cd my-app
npm install
npm run dev
```

</Tab>
<Tab value="pnpm">

```bash
pnpm create signet-app my-app --template full
cd my-app
pnpm install
pnpm run dev
```

</Tab>
<Tab value="bun">

```bash
bunx create-signet-app my-app --template full
cd my-app
bun install
bun run dev
```

</Tab>
</Tabs>

Open `http://localhost:5173`. `full` needs [Bun](https://bun.sh) 1.3+ installed, even when npm or pnpm installs it: `run dev` is a Bun script. It is a web app and an API with sign-in, billing, admin and privacy already wired.
