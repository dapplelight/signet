Signet is a design system and backend kit for React apps. Your app holds only its own business logic.

## How it fits

| Layer | Packages | You get |
| --- | --- | --- |
| Frontend | ui, tokens, lib | Components, themes, API client, forms |
| Backend | server, db, payments, ai | Auth, middleware, tables, billing, models |
| Tooling | create-signet-app, cli, mcp, config, test | Scaffold, copy-in, agents, presets, fakes |

## 60-second start

<Tabs items={["npm", "pnpm", "bun"]}>
<Tab value="npm">

```bash
npx create-signet-app@latest my-app --template full
cd my-app
npm install
npm run dev
```

</Tab>
<Tab value="pnpm">

```bash
pnpm create signet-app my-app --template full
cd my-app
pnpm install
pnpm run dev
```

</Tab>
<Tab value="bun">

```bash
bunx create-signet-app my-app --template full
cd my-app
bun install
bun run dev
```

</Tab>
</Tabs>

Open `http://localhost:5173`. `full` needs [Bun](https://bun.sh) 1.3+ installed, even when npm or pnpm installs it: `run dev` is a Bun script. It is a web app and an API with sign-in, billing, admin and privacy already wired.
