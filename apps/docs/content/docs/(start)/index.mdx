Signet is a design system and backend kit for React apps. Your app holds only its own business logic.

## How it fits

| Layer | Packages | You get |
| --- | --- | --- |
| Frontend | ui, tokens, lib | Components, themes, API client, forms |
| Backend | server, db, payments, ai | Auth, middleware, tables, billing, models |
| Tooling | create-signet-app, cli, mcp, config, test | Scaffold, copy-in, agents, presets, fakes |

## 60-second start

```bash
npx create-signet-app my-app --template full --theme finance
cd my-app
bun install
bun run dev
```

`--template` takes `web`, `api`, `full`, `cli`, `extension` or `desktop`. `--theme` takes `editorial`, `cinematic` or `finance`. `full` gives you a web app and an API with sign-in, billing, admin and privacy already wired.
