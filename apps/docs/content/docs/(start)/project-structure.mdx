| Path | Purpose |
| --- | --- |
| `api/` | `full`: Hono API, env, plans, services, SQLite schema |
| `api/app.ts` | `full`: every route, mounted under `/api` |
| `drizzle/` | `full`: SQL migrations |
| `src/` | The web app: Vite, React, TanStack Router |
| `src/routes/` | One file per page |
| `src/lib/api.ts` | The typed client for the API |
| `test/`, `e2e/` | API tests and the Playwright smoke test |
| `.github/workflows/` | CI: lint, typecheck, test |

The generated env file gets fresh `SESSION_SECRET` and `OTP_SECRET` values in the `full` template. Templates ship `_gitignore` and `_github`, renamed to `.gitignore` and `.github` on scaffold.

Other templates: [Flags and templates](/docs/packages/create-signet-app/flags).
