---
title: "Own a Component's Source"
description: "Copy a signet-ui component into your app, edit it freely, and merge upstream changes later."
---

<Steps>
<Step>
### Install the shared dependencies
```bash
npm i @dapplelight/signet-tokens clsx tailwind-merge
```
</Step>
<Step>
### Copy the component
```bash
bun path/to/signet/packages/cli/src/index.ts add dialog
```
It copies `dialog` and what it imports into `src/components/signet/`. The CLI is not on npm yet: `path/to/signet` is your clone, see [Run from source](/docs/packages/cli#run-from-source-today).
</Step>
<Step>
### Import your copy
```tsx title="src/web/confirm.tsx"
import { Dialog } from "@/components/signet/components/ui/dialog"
```
</Step>
<Step>
### Check the config
```json title="signet.json"
{
  "dir": "src/components/signet",
  "alias": "@/components/signet",
  "items": { "dialog": { "version": "0.2.2", "hash": "…" } }
}
```
Commit `signet.json` and `.signet/`: upgrades merge against them.
</Step>
<Step>
### Upgrade later
```bash
bun path/to/signet/packages/cli/src/index.ts diff dialog
bun path/to/signet/packages/cli/src/index.ts upgrade --dry-run
bun path/to/signet/packages/cli/src/index.ts upgrade dialog
```
Where you and signet-ui changed the same lines, the file keeps git conflict markers. Resolve them, then run lint, typecheck and tests.
</Step>
</Steps>
