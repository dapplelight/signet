### Release: signet-db is public, ready for its first manual publish

`@dapplelight/signet-db` is no longer private, so it is at the same step as `signet-payments` in PUBLISHING.md ("A new package's first release"): CI builds and tests both, but does not publish them. The owner publishes 0.1.0 of each by hand and adds the npm Trusted Publisher, and a later change then adds both to the release order, release-status and publish verification.
